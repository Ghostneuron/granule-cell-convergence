# Current manuscript artifacts

This directory contains the manuscript-facing artifacts for
**"Comparator-relative molecular recurrence in distinct dentate and
cerebellar granule cells"**.

- `JCN_manuscript.md` is the current editable manuscript text.
- `main_figures/Figure_1.png` through `Figure_4.png` are the finalized main
  figures used for submission.
- `source_tables/Table_S1_*.tsv` through `Table_S13_*.tsv` are compact,
  machine-readable repository tables.

The source-table labels are retained for stable cross-referencing and data
auditing. They are repository data files rather than a supplementary-material
upload to JCN. The older project-wide supplementary figures and extended table
collection are exploratory archive material and are not part of this
manuscript's evidentiary set.
