# Comparator-relative granule-cell reanalysis

This directory is the manuscript-matched analysis packet for **"Comparator-
relative molecular recurrence in distinct dentate and cerebellar granule
cells"**.

## Directory layout

- `Project/scripts/build_discovery_robustness.py`: dataset-level inference,
  species stratification, leave-one-dataset-out analysis, matched-null
  sensitivity analysis and module summaries.
- `Project/scripts/analyze_allen_consensus_comparators.py`: independent adult
  mouse Allen common-matrix analysis.
- `Project/scripts/analyze_cross_region_granule_specificity.py`: bidirectional
  Allen cross-region transfer, matched-panel nulls, contrast concordance and
  adult immature-state sensitivity.
- `Project/scripts/build_main_figures.py`: Figures 1-3.
- `Project/scripts/build_supplementary_tables.py`: compact machine-readable
  Tables S1-S13.
- `Project/results/`: compact inputs and derived tables.
- `Project/manuscript/source_tables/`: final Tables S1-S13 in TSV format.

## Environment

Create a Python environment and install:

```bash
python -m pip install -r requirements.txt
```

The scripts were executed with Python 3.11. Randomized procedures use fixed
seeds `205920` and `205921`.

## Inputs not redistributed

The full primary-core rank-delta and gene-summary matrices are omitted because
they are large derived intermediates. Source accessions are listed in Table S1.
To rerun the Allen analysis, set `ALLEN_CONSENSUS_DIR` to a directory containing
the Consensus-WMB-Macosko-10X regional `.h5ad` matrices plus
`cell_to_cluster_membership.csv` and `cluster_to_annotation.csv`.

The included derived tables permit direct auditing of all reported numerical
results, including the cross-region transfer summary in Table S12. The
robustness script additionally requires the full primary-core intermediate
matrices generated by the archived preprocessing workflow.

The packaged Allen library-gene table and deterministic background feature
pool allow `analyze_cross_region_granule_specificity.py` to rerun without the
regional `.h5ad` files. Regenerating those two inputs from source still
requires the Allen matrices described above.

## Analysis order

1. Run `build_discovery_robustness.py` after the primary-core intermediate
   matrices are available.
2. Run `analyze_allen_consensus_comparators.py` with the Allen directory set.
3. Run `analyze_cross_region_granule_specificity.py` after the Allen library-
   level expression table has been generated.
4. Run `build_main_figures.py`.
5. Run `build_supplementary_tables.py` when rebuilding the table packet from
   the full project archive.

The Allen analyses are external adult mouse specificity tests. They are not
developmental replications and do not establish causality.
